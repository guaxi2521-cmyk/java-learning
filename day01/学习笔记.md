## 今天学到的 5 个知识点

### 1. Java 是「先编译、再运行」的两步语言

```
HelloWorld.java  ──javac──>  HelloWorld.class  ──java──>  运行结果
   （人写的源码）              （JVM 读的字节码）
```

- `javac` 是**编译器**，把源码翻译成字节码
- `java` 是**启动器**，把字节码交给 JVM 执行
- `.class` 文件**不要提交到 Git**（已在 `.gitignore` 里排除）

> 对比 C 语言：C 直接编译成机器码（`.exe`），Java 编译成字节码，由 JVM 再翻译。**这就是 Java 能跨平台的原因。**

### 2. 文件名必须和类名完全一致

```java
public class HelloWorld {   // 类名 HelloWorld
```
文件名必须是 `HelloWorld.java`。大小写也算，改成 `helloworld.java` 就报错：

```
错误: 类 HelloWorld 是公共的, 应在名为 HelloWorld.java 的文件中声明
```

### 3. 第一行必须写对：`public static void main(String[] args)`

这一行是程序的**入口**，一个字符都不能改。拆开看：

| 关键字 | 含义 |
|---|---|
| `public` | 公开的，JVM 才能调用到 |
| `static` | 静态的，不用创建对象就能调用 |
| `void` | 没有返回值 |
| `main` | 方法名，**固定叫 main** |
| `String[] args` | 接收命令行参数的数组 |

**现在不用全懂**，先记住「这是我的程序从哪开始跑」就够了。以后学到类和对象时会彻底明白。

### 4. `System.out.println()` 就是「打印一行」

```java
System.out.println("Hello, 世界!");   // 打印完换行
System.out.print("不换行");            // 打印不换行
```

- `System` 首字母大写
- `println` 是 print line 的缩写
- 字符串用**双引号**，末尾有**分号**

### 5. `.class` 文件是编译产物，不用管它

在 VS Code 里点开 `.class` 会看到奇怪代码：

```java
// Source code is decompiled from a .class file using FernFlower decompiler
```

那是**反编译**出来的伪代码，是机器生成的，不是你的源码。**永远改 `.java`，不要改 `.class`。**

## 踩过的坑（都解决了）

| 问题 | 原因 | 解决 |
|---|---|---|
| VS Code 显示 Restricted Mode | 设置文件带 UTF-8 BOM，解析失败 | 用无 BOM 格式重写 `settings.json` |
| 每启动一次插件和配置就消失 | **VS Code 自动更新器**反复重装，删掉 `data` 目录 | 换官方 zip 便携版，关闭 `update.mode` |
| 代码没有语法高亮 | 上面两个原因导致插件未加载 | 换便携版后正常 |
| 打开了奇怪的反编译代码 | 点的是 `HelloWorld.class` 而不是 `.java` | 删掉 `.class`，点蓝色 J 图标的文件 |

> **经验**：`data` 目录的日志在 `data\user-data\logs`，以后出问题先看那里。
